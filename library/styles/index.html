Style lab

Eight visual directions from outside the Alfred design system, each rendering the same page content so only the style differs. Every page ends with an "Adopting this" panel: what the system would add to support the direction, and what collides with the brand.

Off-system by design: these pages use raw hex, foreign type stacks and rule-breaking effects on purpose, and are excluded from the craft verifier. They are references, never product surfaces.
