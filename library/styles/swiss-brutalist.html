Style lab notes

Adopting this

What it would take for the Alfred design system to support the Swiss brutalist direction, and where it fights the brand we already have.

What the design system would add

  • A --font-mono token (JetBrains Mono or IBM Plex Mono free, Berkeley Mono if licensed) for eyebrows, table headers, KPI unit labels, timestamps and metadata chips at 11 to 12px uppercase with +0.06em tracking. It slots under the existing tracked-eyebrow rule and reads "decision instrument", on brand for decision intelligence.
  • A hairline rule system: a token like --rule-hairline (1px, built with color-mix on ink) used as full-bleed section separators and exposed column rules on marketing pages and data tables. It gives the dark site an analyst-terminal structure without touching the palette.
  • The corner and status metadata move: version strings, "last synced 14:02" stamps and bracketed counts like ALERTS [2] set in mono at panel corners, backed by a --text-meta size and tracking token. A natural fit for a product about live decisions.
  • Flat 100% orange #FF8431 and periwinkle #A7A7FC chips and fills for status and category markers in dashboards, replacing tinted alpha washes in those contexts only.

What clashes with the Alfred brand

  • Radius zero everywhere. Alfred's soft 12/24/32px corners are core brand, so going square would make Alfred look like a different company. The compromise: keep the radii but add a 1px visible border token so borders, not shadows, can carry edges on dense data surfaces.
  • The shadow and glow ban. Alfred's diffuse vertical shadows and orange hover glow are signature. At most, add a --shadow-none context for dense tables; the hard 4px offset shadow stays out of the system.
  • The gradient ban clashes fundamentally. The periwinkle to orange gradient is Alfred's one hero effect, and Clash Display stays for headlines. The mono family joins as a third voice for labels only, and mono-brutalist framing never shares a component with the gradient.
Net: adopt the instrument layer (mono labels, hairline rules, corner metadata, flat semantic color chips) as new tokens. Reject radius zero, global shadow removal and the gradient ban, which would erase Alfred's warmth.
